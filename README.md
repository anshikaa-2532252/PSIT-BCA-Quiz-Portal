# PSIT BCA Quiz Portal

A web-based quiz management platform developed using Python Flask, HTML, CSS, and SQLite.

## Features

- Student registration and login
- Teacher dashboard
- Quiz creation and management
- Interactive quizzes
- Countdown timer
- Automatic score calculation
- Result and attempt history
- Quiz leaderboard
- Student performance tracking

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- Git & GitHub
